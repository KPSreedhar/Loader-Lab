# LoaderLab
 
A single-file catalog of 30 pure-CSS loading animations — no dependencies, no build step, no JS frameworks. Open `loaderlab.html` in a browser and it works.
 
## What it does
 
- **30 loaders** across 8 categories (orbit, ring, bar, shape, path, text, morph, glow) — spinners, progress bars, text loaders, and a few unusual ones (compass needle, cassette reels, barcode scan).
- **4 themes** — Bakelite, Night Shift, Blueprint, Mint Lab — switch instantly, no reload.
- **Color control at two levels** — one global picker recolors every loader at once, or override the color of a single loader without touching the rest.
- **Speed control** — a slider scales every animation's duration live, from 0.25× to 2×.
- **Search + category filters** to find a specific loader fast.
- **Favorites**, saved in the browser (`localStorage`), so your picks persist between visits.
- **Copy or download code** for any loader — the modal gives you the exact HTML + CSS to drop into your own project.
## Why it's useful
 
Instead of hunting through blog posts or CodePen for a loading spinner, you get 30 ready-made ones in one page, each with copy-paste-ready code and no attribution or license friction. Picking a theme and a color first means what you copy out already matches your project's palette — you're not re-styling it after the fact.
 
## Tech
 
Plain HTML, CSS custom properties, and vanilla JS — one file, under 40KB, no build tooling required.
